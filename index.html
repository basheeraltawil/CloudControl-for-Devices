CloudControl for Devices

Project Overview for Freelance Software Engineer

The Big Picture: What We're Building

Think of this as building a live, interactive remote control for our hardware devices.

Local Device

Physical devices with Raspberry Pi and touchscreen in the field

Cloud Website

Control any device from anywhere through a web interface

Real-Time Sync

Changes on cloud instantly reflect on device, and vice-versa

Your Main Job: The "Command Center" (Cloud Platform)

You will build the central cloud platform that makes everything work. This is the core of the project.

React
Socket.IO
Python (Flask/FastAPI)
PostgreSQL
WebSockets
JWT Authentication

What You Need to Deliver

A. Cloud Website & Server

  • User login/registration system
  • Dashboard to add/manage devices using serial numbers
  • Control panel for each device matching the device's touchscreen UI

B. Real-Time Communication (Critical)

  • WebSocket (Socket.IO) connections between cloud and devices
  • Instant command delivery from website to devices
  • Real-time synchronization of all UI states

C. Advanced Features

  • Remote firmware updates (OTA) to multiple devices
  • Parameter profiles that can be applied to any device
  • Device status monitoring and logging

How This Fits With Existing Work

Already Complete

Local software on Raspberry Pi (React app + Python script with UART communication)

Your Responsibility

Cloud system and the "agent" that plugs into our existing software for remote control

Phase 4: Testing, Polish, Deployment 1-2 weeks

Quality assurance, documentation, deployment
